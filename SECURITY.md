# Security policy

This is a reference implementation for learning and comparison; the local environment it runs in uses development credentials and plain HTTP. A mistake that would be unsafe once copied (a validation that does not validate, a secret in a log, a vulnerable dependency) is worth reporting.

**Do not open a public issue.** Use GitHub's private reporting: *Security* tab, *Report a vulnerability* ([direct link](https://github.com/dsimonov762/wallpaperhub-java-spring/security/advisories/new)). This is a one-person project; please allow a few days for an answer.

Supported versions: `master` only. Secret scanning with push protection, Dependabot alerts (Renovate raises the updates) and CodeQL are on.
